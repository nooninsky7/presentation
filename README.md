# 🦁 말랑이의 말하기 탐험대 (공식 릴리즈 v1.0)
> **초등 2학년을 위한 5단계 생각 스피치 & 다정한 선생님 AI 인터뷰 웹앱**  
> 2022 개정 대한민국 국어과 교육과정 성취기준 공식 교과 단원 제재 114종 수록

## ✨ 핵심 기능 및 교육적 장치

1. **사다리식 생각 쪼개기 (AI 인터뷰 모드)**
   - 한 번에 발표하지 않고, 다정한 여성 선생님 목소리로 3번의 질문을 주고받으며 생각을 하나씩 꺼냅니다.
   - 대화가 끝나면 자동으로 완성된 3문장 발표 원고를 조립해 줍니다.
2. **태블릿 가로 모드 (Widescreen 2분할 인체공학 구조)**
   - 좌측 화면: 오늘의 발표 주제와 생각 정리 힌트 카드
   - 우측 화면: 사다리 스텝 바, 타이머, 마이크 녹음 버튼, 사자 볼륨 게이지, 부모님 완료 버튼
   - 아이가 책상에 태블릿을 거치하고 힌트를 눈으로 보며 바로 발표할 수 있습니다.
3. **6초 여유로운 워밍업 루틴**
   - 녹음 전 차분하게 긴장을 풀어주는 3단계 준비 루틴:
     - `[3]` 🧘 1단계: 허리 펴고 바른 자세! (2초)
     - `[2]` 💨 2단계: 숨 한번 크게 들이쉬고~ (2초)
     - `[1]` 😊 3단계: 방긋 웃으며 출발! (2초)
4. **사자 목소리 볼륨 게이지 (실시간 마이크 피드백)**
   - `🐜 개미 목소리` ➔ `🐿️ 다람쥐 목소리` ➔ `🦁 멋진 사자 목소리!`
   - 교실 끝까지 들리는 자신감 있는 발성을 시각적으로 피드백 (언제든 ON/OFF 스위치로 켜고 끄기 가능).
5. **녹음 없이 부모님과 말하기 완료 버튼**
   - 꼭 기계에 녹음하지 않아도, 부모님과 마주보고 이야기 나눈 것만으로 스티커와 달력 도장을 받을 수 있습니다.
6. **주 1~2회 실천 추적 루틴 달력**
   - 월간 달력에 동그라미 스탬프와 별(🌟)이 콕 찍히며, 날짜를 터치하면 당일 수행한 발표 제목과 녹음을 다시 들을 수 있습니다.
7. **프라이버시 & 오프라인 안심 저장**
   - 아이의 음성 및 연습 데이터는 일체 외부 서버로 전송되지 않고, 오직 접속 기기의 내부 로컬 저장소(LocalStorage)에만 안전하게 보관됩니다.

## 💾 파일 구조
- `index.html`: 단독 실행 가능한 반응형 모바일/태블릿 단일 페이지 웹앱 (HTML, CSS, JS 내장)
- `server.ps1`: 가정 내 동일 Wi-Fi 접속을 위한 로컬 웹 서버
- `start.bat`: PC에서 원클릭으로 로컬 웹 서버와 브라우저를 실행하는 배치 파일
- `말랑이_발표연습_바로가기.url`: 바탕화면 원클릭 접속 바로가기
